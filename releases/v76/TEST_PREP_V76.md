# TEST PREP — V76 Provider-neutral media adapter conformance

Base/rollback anchor: main V75 `64619fbfe3967868a88085c4c4084ddcce4759ac`. V76 is independently testable and must not require sibling media branches.

## Deterministic contract tests
- Fixed fake image/STT/TTS adapters produce byte/text-identical results and stable capability metadata across repeated runs.
- Validate image request fields and decoded artifact MIME/dimensions; PCM16 framing/rate/channel constraints; TTS text/format constraints.
- Reject malformed/empty input, oversized prompt/text/audio/image request, oversized response/artifact/transcript, invalid capability metadata, wrong MIME/codec, empty image/audio artifact, empty/whitespace STT transcript.
- Missing provider/adapter, timeout, provider exception/error status, cancellation and malformed provider response fail closed with bounded error types and no partial success claim.
- Fixtures are checked-in, minimal, deterministic and hashable; no network dependency for unit tests.

## Concrete adapter evidence gate
No real image generation, transcription or synthesis claim unless that concrete adapter is independently exercised on the exact candidate HEAD. Image: real backend invocation + decodable non-empty artifact + declared MIME/dimensions. STT: known-speech fixture + non-empty expected transcript evidence. TTS: fixed text + decodable non-empty audio + declared codec/rate evidence. Record adapter identity/version/config (excluding secrets), request/response hashes or safe metadata, timestamps/status and reproducible invocation. Stub/mock success never satisfies this gate.

## Resource / privacy
For each adapter probe record wall latency, peak RSS delta, input/output bytes and temporary-storage high-water mark; flag unbounded growth. Where feasible record Android/host battery impact separately from unit CI. Retention defaults OFF: prompts, transcripts, PCM/raw audio and generated bytes are not persisted; metrics/logs contain sizes/timing/status only; secrets never enter evidence/logs. Assert cleanup after success, error, timeout and cancellation.

## Android/host audio gate
V76 core does not itself acquire/play audio. Any concrete Android/host STT/TTS integration additionally requires permission-denied/granted/revoked behavior, microphone open/close/reopen lifecycle, audio-focus acquire/loss/reacquire, interruption/cancellation, speaker/output start/stop/release, cleanup on exceptions, no raw-audio retention by default, plus latency/RAM/battery measurements where feasible. These platform tests cannot be replaced by host mocks.

## Voice boundary
Half-duplex remains the only baseline voice composition. Full-duplex, barge-in, echo cancellation, wake-word and streaming require separate implementations and dedicated tests before any claim.

## Regression matrix
On the exact candidate HEAD, Python 3.11 and 3.12: compileall; V76 focused tests; V75/V74/V73/V72/V71/V70/V69 regressions; V66 operational, V67 code-factory and V68 code-factory core regressions. Preserve V69 fail-closed media contracts and V70 adapter validation behavior; do not weaken/skip prior tests to obtain green CI.

## Promotion / rollback
KEEP only when focused deterministic/negative/privacy/resource tests and the full regression matrix pass on the same HEAD. Concrete media capability remains DEFERRED unless its real adapter evidence gate passes independently. REPLACE/disable an adapter on contract drift, unverifiable backend identity, privacy/retention violation, unbounded resource use, repeated timeout/error, wrong MIME/codec, empty output, or irreproducible evidence. Roll back the whole V76 layer to main V75 `64619fbfe3967868a88085c4c4084ddcce4759ac` if core regressions fail.
