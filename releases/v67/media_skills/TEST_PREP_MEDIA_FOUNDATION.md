# Media Foundation TEST_PREP

Verify contracts deterministically from a clean checkout: canonical artifact metadata/SHA-256, stable request serialization, malformed/empty bytes, blank/invalid MIME, wrong media family, unsupported parameters, and duplicate/provenance identifiers. Missing provider must return `needs_provider`, never success. Fake providers must cover timeout, exception, cancellation, empty artifact, wrong MIME, oversized artifact, and metadata mismatch. Fixtures must be byte-pinned with expected SHA-256. Record CPU time, peak RAM, artifact bytes, and validation latency. Assert secrets/raw microphone data are absent from logs/manifests by default and retention is opt-in. Android adapters remain outside the foundation contract. Promotion requires an independently exercised concrete adapter per claimed media capability; otherwise capability remains provider-required. Rollback/disable: unregister adapter and preserve contract-only behavior.
