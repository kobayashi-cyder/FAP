# Audio Input / STT TEST_PREP

Use pinned PCM16 fixtures: silence, tone/noise, speech-like synthetic envelope, odd-byte/truncated PCM, unsupported sample rate/channels, empty and oversized buffers. Deterministically verify RMS/VAD/chunk assembly and dropped/reordered chunk handling. STT absent -> `needs_provider`; timeout, cancellation, exception, empty/whitespace transcript, malformed timestamps/confidence and provider mismatch fail closed. A real STT claim requires independently exercised audio fixture with expected transcript tolerance and measured WER/latency; provider response alone is insufficient. Android tests require RECORD_AUDIO permission denied/granted/revoked, mic start/stop/restart, background/lifecycle interruption, audio focus interactions, resource release and no stuck recorder. Record capture/STT latency, peak RAM, buffer bytes, CPU/battery proxy. Raw microphone retention defaults off; logs/manifests contain only explicitly permitted derived evidence. Rollback/disable: stop/release mic and unregister STT adapter.
