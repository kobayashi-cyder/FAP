## Negative tests
Missing/invalid credential; unavailable backend; timeout/cancel/stale completion; empty/truncated/non-image bytes; MIME/signature/dimension mismatch; unsupported format; dimension/byte budget+1; malformed provider metadata; duplicate completion; secret/prompt/output leakage; retention when disabled. Fail closed; never translate these into generated-image success.

## Android / privacy / resources
No new Android storage/media permission is required by this prep. Use app-private/cache storage and lifecycle cancellation; INTERNET belongs only to a concrete network adapter. Credentials, prompts and generated bytes are not logged; artifact persistence is opt-in and retention defaults to zero. Evidence records requested/actual dimensions, bytes, decode and provider wall latency, peak RSS delta where measurable, temporary/persisted storage bytes, and repeated-call handle/RAM growth; unsupported metrics are `unavailable`, never estimated.

## Promotion evidence
A real-generation KEEP requires exact backend/adapter identity, independent invocation, independent image decode, MIME/dimensions/content hash, negative-suite PASS, resource measurements, and no default secret/payload retention. Existing deterministic prototype tests are not evidence of real generation.

## DEFER / REPLACE
DEFER generation if backend, credential, runtime or independent decoder evidence is unavailable. REPLACE/split if provider schemas leak into core, cancellation/bounds are nondeterministic, retention becomes implicit, Android broad-storage permission is required, or measured resource growth/regression is unexplained. Keep video, STT/TTS, microphone/output lifecycle, full-duplex, barge-in, echo cancellation, wake-word and streaming separate.
