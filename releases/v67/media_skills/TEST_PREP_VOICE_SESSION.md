# Voice Session TEST_PREP

Baseline claim is half-duplex single-turn only. Deterministically test monotonic phases `idle -> capture -> stt -> respond -> tts -> playback -> idle`, stable turn/session IDs, cancellation at every boundary, and restart after failure. Feed pinned PCM fixtures and fake STT/responder/TTS outputs. Missing STT/TTS must propagate `needs_provider`; timeout/exception/empty transcript/empty response/wrong-MIME/empty audio must fail closed without advancing to a false completed turn. Android tests require mic permission revoke, AudioRecord/AudioTrack lifecycle, audio-focus loss, incoming interruption/backgrounding, mic released before speaker path where required, and no leaked recorder/player. Record phase latency, end-to-end latency, peak RAM, buffer bytes and battery proxy. Raw mic/audio retention defaults off; transcript/response retention must be explicit and deletable. Full-duplex, streaming partial STT/TTS, barge-in, echo cancellation, wake-word and jitter handling remain DEFERRED and require separate real-device test plans/evidence before any claim. Rollback/disable: terminate current turn, release mic/player/focus, unregister adapters, return to text/provider-required mode.
