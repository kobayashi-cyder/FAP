# Video Skill TEST_PREP

Deterministic tests: scene ordering, frame boundaries, FPS/duration rounding, schema version, pinned asset digests, and byte-stable render-plan JSON. Reject empty scenes, overlaps/gaps outside contract, invalid FPS/dimensions/duration, missing or digest-mismatched assets. Renderer absent -> `needs_provider`; timeout, cancellation, crash, empty output, wrong MIME/container, truncated file, duration/dimension/FPS mismatch fail closed. Concrete renderer evidence must use a clean-checkout short fixture and independently inspect output metadata; a Remotion/ffmpeg/provider success code alone is not evidence. Measure render wall time, peak RAM/CPU, temp bytes, final bytes and cancellation cleanup. Android tests, if rendering/playback is exposed there, require lifecycle cancellation and storage-pressure behavior. Privacy/provenance: pin external assets; no silent network substitution. Rollback/disable: unregister renderer and retain plan-only mode.
