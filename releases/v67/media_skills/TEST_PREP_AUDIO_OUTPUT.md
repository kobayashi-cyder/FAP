# Audio Output / TTS TEST_PREP

Deterministically test text validation/chunking at sentence boundaries, voice/rate parameters, and pinned fake audio SHA. Reject blank/oversized text, unsupported rate/voice, corrupt/truncated audio. TTS absent -> `needs_provider`; timeout, cancellation, exception, empty artifact, wrong MIME, invalid sample metadata, clipping/invalid duration fail closed. Real synthesis requires independently decoded audio with duration/sample-rate/channel/loudness checks; provider success is not sufficient. Android tests require audio-focus gain/loss, duck/pause policy, AudioTrack/playback start-stop-restart, interruption, background lifecycle, cancellation and resource release. Record first-audio latency, total synthesis time, peak RAM, audio bytes and CPU/battery proxy. Text/audio retention must be explicit; secrets/provider tokens never logged. Rollback/disable: stop playback, release focus/resources, unregister TTS adapter.
