# TEST PREP — V77 Concrete image HTTP adapter

Base/rollback anchor: main V75 `64619fbfe3967868a88085c4c4084ddcce4759ac`. V77 is independently testable from this anchor and must not require V76 or sibling media lanes.

## Deterministic contract / negative tests
- Checked-in hashable fixture transport returns byte-identical image response and stable metadata on repeat runs; no network in unit tests.
- Reject empty/malformed prompt/request, invalid dimensions/format/metadata, request over configured byte/character/dimension limits, response/download over byte/dimension limits, malformed JSON, missing payload/URL, truncated/undecodable bytes, wrong/unsupported MIME, empty artifact, redirect/download failure.
- Missing provider/credentials, DNS/connect failure, timeout, cancellation, HTTP 4xx/5xx/rate-limit and provider error fail closed with bounded/redacted errors and no partial-success claim.
- Validate MIME from decoded artifact, not provider declaration alone; enforce decode-bomb/dimension limits before exposing success.

## Real-backend evidence gate
No **real image generation** claim unless the exact candidate SHA independently exercises the concrete HTTP provider plus renderer/decoder against a real backend. Evidence: adapter/provider identity and version/config class (no secret), timestamp/status, reproducible invocation description, validated non-empty decodable artifact, MIME/dimensions/encoded bytes/hash, latency and resource metrics. Mock/fixture success proves contract behavior only. Provider retention policy must be identified separately where knowable.

## Resource / privacy
Record wall latency (p50/p95 when repeated), peak RSS delta, request/response bytes, decoded dimensions/estimated decoded bytes, temporary-storage high-water mark and cleanup; Android where feasible also records battery impact and verifies no main-thread network/decode. Prompts, credentials, response bodies and generated bytes are ephemeral by default; logs/evidence contain only redacted status/error class, sizes/timing and safe hashes/metadata. Assert cleanup after success, error, timeout and cancellation. No broad storage permission; app-private/cache unless explicit export. Credentials never embedded in APK assets.

## Regression matrix
Exact candidate HEAD on Python 3.11/3.12: compileall; V77 focused tests; current V75/V74/V73/V72/V71/V70/V69 regressions; V66 operational + V67/V68 code-factory core regressions. Preserve V69 fail-closed media contracts and V70 adapter validation. No skip/xfail/test deletion to obtain green CI.

## Scope boundary / rollback
V77 introduces no mic, audio-focus, speaker, STT/TTS or voice-session claim. Those remain isolated. KEEP core adapter only when deterministic/negative/privacy/resource tests and regression matrix pass same HEAD. Real generation remains DEFERRED until live evidence gate passes. Disable/REPLACE adapter on contract/API/auth drift, unverifiable backend identity, privacy/retention violation, repeated timeout/error, wrong MIME, empty/undecodable output, unbounded resource use or irreproducible evidence. Roll back V77 to main V75 `64619fbfe3967868a88085c4c4084ddcce4759ac` on core regression.
