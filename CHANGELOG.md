# Changelog

## 1.0.01 — candidate

- Add a deterministic mildly dense initial routing graph.
- Add dynamic sparsification for routine work and risk-triggered re-densification.
- Add context-aware edge rewiring from capability, failure, uncertainty, novelty, and learned utility signals.
- Add bounded beam search over route sequences rather than node-only Top-k selection.
- Add reusable route/task/capability/failure affinity learning.
- Add tamper-evident, public-safe persistence for generic routing state.
- Add a routing mechanism benchmark and unit tests.
- Define GPT-5.6 Sol-class performance as an evidence-gated target, not a current claim.
