# FAP Intelligence Target — 1.0.01

## Target

Long-term target: GPT-5.6 Sol-class task performance under explicit, reproducible
benchmarks.

This is a target, not a current claim.

## What 1.0.01 changes

FAP 1.0.01 begins moving intelligence allocation into the routing structure:

- mildly dense initial routing graph;
- dynamic sparse topology after warm-up;
- route-specific online utility learning;
- reusable task-family/task-form/capability affinities;
- failure-specialist routing;
- graph propagation over active route edges;
- route-transition reinforcement;
- bounded pruning and edge reactivation;
- risk-triggered temporary re-densification.

## Promotion evidence required

Before any claim of GPT-5.6 Sol-level performance, record at minimum:

- frozen benchmark commit SHA;
- unseen holdout set;
- per-domain accuracy;
- aggregate accuracy;
- calibration/error rate;
- tool-routing accuracy;
- route-selection regret against an oracle or hindsight best route;
- latency;
- route count;
- active-edge density;
- total compute budget;
- timeout rate;
- regression status.

The dynamic-sparse benchmark in 1.0.01 validates routing mechanics only. It does
not validate GPT-equivalence.
