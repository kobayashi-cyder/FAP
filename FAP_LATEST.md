# FAP latest development snapshot

Current mainline: **V87.19 — Autonomous Verified Media Skills**.

V87.19 turns image/video generation engines into FAP-managed autonomous skills.

Current media path:

`discover engine -> candidate skill -> generate real bytes -> persist artifact -> observe actual file -> independent critic -> verified outcome -> testing -> shadow -> active`

New in V87.19:
- generalized HTTPS image and video generation engine adapter;
- synchronous image/video generation responses;
- bounded asynchronous job polling for long-running video generation;
- same-origin restriction on async poll URLs;
- credentials referenced only by environment-variable name;
- generated bytes persisted atomically to disk;
- SHA-256 artifact identity before observation and critique;
- image/video MIME validation;
- engine discovery via `FAP_MEDIA_ENGINES_JSON`;
- autonomous media skill IDs:
  - `media.generate.image:<engine>`
  - `media.generate.video:<engine>`
- candidate -> testing -> shadow -> active promotion from repeated independent verified success;
- duplicate artifacts do not count toward promotion;
- never-successful repeatedly failing engines can be rejected;
- V87.17 adaptive routing selects among eligible generation skills.

Important boundary:
V87.19 provides the production generation-engine host and autonomous skill lifecycle, but it does not bundle a specific third-party image/video model or provider credential. A configured compatible engine is required for real-world media generation. External provider output is never represented as native FAP generation.
